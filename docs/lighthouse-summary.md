## PWA

В Lighthouse 12+ категорию PWA убрали, поэтому установку проверили вручную:

- `manifest.webmanifest` валиден: название, `start_url`, `display: standalone`, `theme_color`, иконки 192, 512 и maskable 512;
- service worker регистрируется и управляет страницей;
- после включения офлайна и перезагрузки приложение открывается и рисует полку проектов — проверено через Chrome DevTools Protocol.

## Как повторить

```bash
npm run build
python3 -m http.server 4173 --directory dist
CHROME_PATH="/путь/к/Google Chrome for Testing" \
  npx lighthouse@13.6.0 http://localhost:4173/ --preset=desktop
```

Полные отчёты: `docs/lighthouse/desktop.report.html`, `tablet-1280x800.report.html`, `mobile-390.report.html`.
