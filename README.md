# Заметно

Дневник наблюдений для школьников 10+: проекты, фотографии, заметки, измерения, сравнение снимков, напоминания и презентация PPTX. Работает офлайн, данные хранятся в браузере устройства.

## Локальный запуск

```bash
npm ci
npm run dev
```

Открой `http://localhost:5173/`.

Проверка на планшете в той же Wi-Fi-сети:

```bash
npm run dev -- --host
```

Vite покажет сетевой адрес. Это быстрый просмотр без установки и офлайн-режима.

## Тесты и сборка

```bash
npm test
npm run build
```

## Публикация

При push в `main` GitHub Actions собирает приложение и публикует его на GitHub Pages:

**https://nbobrova196.github.io/zametno/**

Сборка для GitHub Pages запускается с `--mode github`, чтобы адреса ресурсов и маршруты начинались с `/zametno/`.

Если первый деплой не запустился, открой в репозитории **Settings → Pages** и выбери источник **GitHub Actions**, затем перезапусти workflow.

## Установка

### Android-планшет

1. Открой ссылку на GitHub Pages в Chrome.
2. Меню ⋮ → **«Установить приложение»** (на старых версиях — «Добавить на главный экран»).
3. После первого открытия приложение работает офлайн.

### Компьютер

1. Открой ссылку в Chrome или Edge.
2. Нажми значок установки в адресной строке либо меню ⋮ → **«Установить приложение»**.

Отдельного APK или EXE нет: это PWA, которая ставится из браузера.

## Перенос проекта

1. На исходном устройстве: проект → **Настройки** → **«Скачать архив»**.
2. Передай ZIP на другое устройство любым способом.
3. На другом устройстве: полка → **«Импортировать»** и выбери архив.

Импорт создаёт копию проекта. Исходный проект остаётся на месте.

## Приватность

На хостинге лежат только файлы приложения. Проекты, фотографии и заметки не отправляются на сервер — они хранятся в IndexedDB браузера. Удаление данных сайта в браузере удаляет и проекты, поэтому важные архивы стоит сохранять.
